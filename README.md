## Tentang saya

Saya mahasiswa **Sistem Informasi di Universitas Bina Sarana Informatika** dan seorang **Fullstack Developer**. Saya menikmati proses membangun aplikasi dari antarmuka sampai ke basis data, lalu merapikan cara aplikasi itu dirilis.

Saya pernah mengembangkan **Taxation Map**, tempat pengguna dapat menandai objek pajak, menyunting batas pada peta, dan memperbarui atributnya. Di sisi DevOps, saya menggunakan **Python** dan **Docker** untuk membantu mengotomatiskan deployment, serta **GitHub Actions** untuk CI/CD pada proyek mandiri.

Saat ini, fokus saya ada di:

- 🌐 Aplikasi web fullstack
- 🗺️ Pemetaan dan fitur geospasial
- ⚙️ Otomatisasi deployment dan CI/CD
